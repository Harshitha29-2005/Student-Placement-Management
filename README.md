# Student Placement Management System

## 📌 Project Overview
The **Student Placement Management System** is a Java-based application developed to simplify and organize the campus recruitment process. It helps manage student details, company information, job openings, and student job applications through a structured system integrated with a MySQL database.

## ✨ Features
- **Student Management:** Store and manage student information.
- **Company Management:** Maintain company details.
- **Job Opening Management:** Organize available job opportunities.
- **Job Applications:** Allow students to apply for available job openings.
- **Database Connectivity:** Use JDBC to interact with a MySQL database.
- **Data Management:** Perform database operations using SQL queries.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Tools:** Eclipse / Visual Studio Code, MySQL Workbench
- **Version Control:** Git and GitHub

## ⚙️ Prerequisites
- Java Development Kit (JDK)
- MySQL Server
- MySQL Workbench (optional)
- Eclipse or Visual Studio Code
- MySQL JDBC Driver

## 🚀 Getting Started
1. Clone this repository:
   ```bash
   git clone https://github.com/Harshitha29-2005/Student-Placement-Management.git
   ```
2. Open the project in Eclipse or Visual Studio Code.
3. Create the required database and tables in MySQL.
4. Configure your database URL, username, and password in `DBConnection.java`.
5. Ensure the MySQL JDBC Driver is added to the project.
6. Run `Main.java` to start the application.

## 🎯 Project Objective
The objective of this project is to demonstrate Java programming, object-oriented programming concepts, JDBC connectivity, SQL operations, and database-driven application development.
